# supreethgowda.com

Supreeth Gowda's personal journal, built with Jekyll and hosted on GitHub Pages.

## Local development

1. Install Ruby and Bundler.
2. Run `bundle install`.
3. Run `bundle exec jekyll serve`.
4. Open `http://localhost:4000`.

Journal entries live in `_posts`. Add `published: false` to front matter while an entry is still a draft.

The site intentionally uses a small custom stylesheet and no frontend framework. JavaScript is loaded only on the legacy COVID-19 project page for its accordion.
